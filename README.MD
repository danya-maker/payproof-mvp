# PayProof

PayProof — MVP для прозрачной фиксации выплат между работодателем и сотрудником.

## Problem

Задержки зарплаты могут приводить к спорам между сотрудником и работодателем. История выплат не всегда удобна для проверки и подтверждения.

## Solution

PayProof создаёт единую историю выплат и фиксирует ключевые события, чтобы сделать историю платежей более прозрачной и проверяемой.

## MVP

- история выплат;
- фиксация новой выплаты;
- отслеживание просрочек;
- счётчик задержек;
- предупреждение после третьей просрочки;
- концепция фиксации событий в Solana.
